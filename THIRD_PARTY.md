# Third-party code

## Herdr agent identifiers

The provider catalog in `src/provider.rs` follows the canonical agent names and
alias rules in `src/detect/mod.rs` from
[Herdr v0.9.5](https://github.com/herdrdev/herdr/tree/v0.9.5), commit
`2ecf19a92fc3a7fff75b6ce3655ef04f4625ec01`.
Its brand-to-ANSI color choices are specific to this plugin.
